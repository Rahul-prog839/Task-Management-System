# Task Management System – Frontend

This directory contains the frontend of the Task Management System, a productivity application built using React.js.

The frontend provides an interactive and responsive interface for managing tasks, to-do lists, personal notes, reminders, and productivity insights.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Axios
- React Router
- Material UI
- Recharts
- React Icons
- React Toastify
- AOS (Animate On Scroll)

## Features

- User registration and login interface.
- Google and GitHub authentication integration.
- Interactive productivity dashboard.
- Task creation, management, and tracking.
- Calendar view for task deadlines.
- To-do list management.
- Personal notes management.
- Notifications and reminders.
- Light mode and dark mode.
- Responsive user interface.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Navigate to the frontend directory:

```bash
cd FrontEnd
```

Install dependencies:

```bash
npm install
```

### Environment Configuration

Create a `.env` file inside the `FrontEnd` directory:

```env
REACT_APP_API_URL=http://localhost:8080
```

### Run the Application

Start the React development server:

```bash
npm start
```

The frontend will be available at:

```text
http://localhost:3000
```

Make sure the backend server is running before using the application features that require API access.

## Backend Integration

The frontend communicates with the Node.js and Express.js backend using Axios.

The backend handles:

- User authentication.
- Database operations.
- Task management.
- Notes and to-do operations.
- Notifications and reminders.

For complete project setup instructions, backend configuration, database details, and application screenshots, refer to the main [README](../README.md).
